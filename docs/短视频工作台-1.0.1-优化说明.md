## 有界客户端契约复核

本次登录检测、调度和兼容字段变化使旧的 Bilibili 实现哈希锁失效。复核后更新固定源哈希；没有修改固定 API 目标、请求方法、同源跳转上限、凭据所属分区、网络租约或出口策略，也没有将其他平台标记为已审查。源文件再次变更仍会使锁失效。

对应回归：login-detector、gated-session-probe、account-service.network、exclusive-business.integration、reviewed-operation-catalog。只把客户端契约回归与源版本绑定，不将其当成平台服务端有效登录或实际网络出口的证明。
