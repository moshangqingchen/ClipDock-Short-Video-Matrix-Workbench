## 使用入口与范围

在“国际账号”配置开发者应用并完成官方授权后，点击该账号的“读取数据”。每次取得当前代理资格后，经同一 `ProxyTransport` 调用固定官方接口；打开页面只读本机历史快照，不会自动请求平台。最多返回 20 条作品，不自动翻页；界面显示实际抓取时间、权限状态和未知值“—”。取消后旧结果不会覆盖页面或数据库。

- YouTube：频道资料、平台返回的频道统计及 uploads 列表中的最多 20 个视频，最多 3 个请求。
- TikTok：当前应用只申请 `user.info.basic`，因此只读取基础资料。`user.info.stats` 与 `video.list` 未获授时不发对应请求，明确显示缺少权限；不能凭修改本地字符串补齐官方审批或用户授权。
- X：用户资料、公开统计及最多 20 条本人帖子，2 个请求。额度／付费权限不足时如实拒绝或标记可选部分受限；曝光不能理解为视频播放量。

身份校验、精确字段、计数口径、权限及官方来源见[只读适配器](global-read-adapter.md)。读取成功不代表上传或发布能力可用。

## 凭据与生命周期

`GlobalReadService` 在主进程组合资格、读取器、刷新器和 SQLite 仓库。临近过期且存在 refresh token 时尝试一次官方刷新；已知刷新期限必须有效。刷新前后复核原账号、应用及旧凭据，`commitRefresh` 在事务内比较当前 Token 与旧 Token；迟到刷新不能覆盖新授权。Token、秘密和原始 API 响应不进入 IPC、快照或备份。

v1 加密 envelope 新增可选 `refreshExpiresAt`，旧数据仍可读。初次 TikTok 兑换按 `refresh_expires_in` 保存实际期限；Google 仅在返回 `refresh_token_expires_in` 时保存。旧 TikTok 凭据缺少明确刷新期限时要求重新授权，不猜测签发时间。详细行为见[刷新合同](oauth-refresh-contract.md)。

迁移 8 只增加 `global_read_snapshots`，每账号一份显式 schema 的公开快照，外键随国际账号删除。快照与现有 `audit_events` 的 `GlobalRead` 记录同事务提交；审计只有平台、作品数及能力状态。未知、损坏、跨账号或跨远端身份的数据不会投影给界面。该表不保存出网许可，主进程重启仍重新取证。

网络、配置、秘密变更、挂起、账号清除与重新授权均撤销进行中的读取；收到 401 只返回固定重新授权提示，不把网络故障写成账号离线。公开取消可以立即结束等待，原工作槽及退出仍等实际依赖清理；不因取消就偷偷发起替代任务。
