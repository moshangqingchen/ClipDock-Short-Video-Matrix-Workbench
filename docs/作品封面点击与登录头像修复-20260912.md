# 作品封面、作品入口与登录头像（2026-09-12）

## 原因与修改

原程序的远程图片授权回调固定返回未启用，严格模式又仅向界面提供本地缓存图片，历史远程图片地址已清空，因此封面与账号头像始终为空。作品榜使用普通容器，没有打开作品的点击入口。

- 国内模式下，允许从当前账号自己的平台图片域下载头像与作品封面，并继续受该账号网络许可约束；代理切换或账号重置会取消在途下载。图片不携带登录 Cookie，校验格式、大小后缓存为本地 PNG；界面仅读取本地缓存。
- 对既定平台图片域的旧 HTTP 引用升级至相同地址的 HTTPS；不进行 HTTP 回退，不放通任意图片地址或平台 API。
- 主页确认本人登录后，只提取本人账号控件或本人登录资料中的头像，不采集推荐作者头像，不覆盖保存的账号名称或账号 ID。
- 同一图片在 5 分钟内复用下载及缓存，避免每次登录检查都重复下载。媒体使用已注册的持久账号会话，不依赖隐藏网页是否被关闭。
- 对没有图片缓存的账号安排一次补全，使用现有账号采集流程取新图片源；正在浏览公共主页时延后，实际请求采集后才消耗本次补全机会。
- 作品榜、数据抽屉和观测面板的封面、标题及整卡支持点击与键盘打开。使用作品所属账号的会话；先显示该账号视图，再导航至作品，防止后台采集抢占。无有效作品链接的卡片禁用。
- 普通点击账号继续默认进入平台主页。
