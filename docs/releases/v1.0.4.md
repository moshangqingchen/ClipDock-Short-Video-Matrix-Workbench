# ClipDock 短视频矩阵工作台 v1.0.4

更新日期：2026-09-14。适用于 Windows 10/11 x64。

## 页面加载与扫码跳转

- 修复规则模式下，代理内核已建立连接但连接列表尚未更新时，软件过早拒绝转发，导致视频号主页白屏并报 `ERR_TUNNEL_CONNECTION_FAILED` 的问题。只对尚未出现的国内连接记录进行短暂、有上限的等待；仍使用真实连接记录核验，不放宽账号隔离和路由检查。
- 等待过程中断网、取消或切换配置时立即停止；超时或证据不完整时继续拒绝连接，不会绕过验证。
- 修复网页原生显示层遮住加载错误提示和“重新加载”按钮的问题。错误提示现在占用独立空间，说明扫码后发生连接错误不等于登录失效。

## 下载与升级

- `ClipDock-1.0.4-setup.exe`：安装版。
- `ClipDock-1.0.4-portable.exe`：免安装版。
- `SHA256SUMS.txt`：校验值。

升级保留账号及原浏览器登录环境。已过期或未完成的平台登录仍需扫码；软件不会伪造登录成功状态。
