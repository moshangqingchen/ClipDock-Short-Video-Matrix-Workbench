# 1.1.0-rc.4 · 抖音精选资料同步

修复抖音官方页面已经改名换头像，工作台仍显示旧昵称的问题。新版抖音精选已移除旧代码依赖的初始账号对象，原资料观察器又只覆盖创作者后台，导致主页的当前资料没有完整进入同步流程。

- 被动观察抖音主页正常返回的自身资料响应，更新昵称、头像及平台提供的统计字段，不新增资料请求。
- 在“我的”页面读取与顶栏头像资产一致的当前昵称；支持头像尺寸、格式和签名不同的同一资产，保留原始下载地址。
- 排除公共作者资料、指定其他用户的查询、推荐流、隐藏元素和账号切换中的冲突信息，继续使用已有资料版本检查及头像缓存。
- 延续 rc.1–rc.3 的界面、采集质量和主页／后台独立登录状态修复。
- 安装维护启动器的报告与临时工作目录统一放在项目 `output/temp/`，现有账号数据及登录环境继续沿用。

实现与官方静态证据来源见[抖音资料同步说明](../douyin-profile-sync.md)。手机或其他浏览器修改资料后，仍需工作台正常取得新的官方资料响应或加载自身页面才会同步。

构建目录：`release/douyin-profile-1.1.0-rc.4/`。
本机测试、备份、覆盖安装与核验记录：`output/douyin-profile-fix/release-rc4/`。

验证：206 个测试文件、5,352 项测试全部通过；安装维护备份专项 21 项通过。TypeScript、ESLint、生产构建与 NSIS 安装包生成通过。全量测试采用 4 个 worker，以避免本机高并发导致模块导入超时；测试和构建输出均位于项目目录。

打包程序完整启动检查通过，涵盖工作区、网络、消息布局、数据观测及国内外账号 IPC 边界。离线重试控件的几何检查先等待本次导航产生真实错误并完成渲染，避免把尚未出现的控件误报为页面遮挡；原几何断言保持不变。
