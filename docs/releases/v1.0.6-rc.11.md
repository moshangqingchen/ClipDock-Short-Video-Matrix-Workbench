# 1.0.6-rc.11

修复登录检查、连接恢复与发布操作中的确定性问题。针对正常退出后快手和视频号再次要求扫码的反馈，排查发现快手主页与管理后台票据期限不同，既有视频号身份响应也曾明确离线；现有记录无法确定平台服务端失效的具体触发原因，不能承诺此次更新后永不掉登录。

## 登录与连接

- 允许保活任务执行自己的主页复核，仍保护其他采集、编辑和消息任务。程序退出后不会继续执行保活。
- 主页未登录界面须连续稳定 3 秒才确认。Cookie 变化重置观察，导航和加载失败丢弃旧结论，临时检查页保留到复核完成。
- 分别记录主页和管理后台的身份确认。界面显示最近确认时间、本次检查结果和连接状态，提供对应登录入口、复核及重建连接操作。
- 网络恢复优先恢复用户选择的安全只读页面。扫码、编辑和消息页面中断后明确提示，由用户选择入口；后台任务不覆盖此提示。
- 重建失败连接保留原账号分区及 Cookie，关闭旧连接完成后再重建网络上下文。
- 补充启动/退出保存阶段、关键 Cookie 的到期和删除原因、身份接口 HTTP 状态及平台数字错误码。审计不记录 Cookie 值、令牌、响应正文或 URL 查询串。

## 体验与流畅性

- 国内和国外发布草稿按账号自动保存；存储失败明确提示并保留内存草稿。异步保存与上传完成不覆盖新文案、不抢回旧账号。
- 官网工作区提供发布侧栏，可查看素材、填入文件、复制文案并保存计划。窄窗口把辅助面板放在下方。
- 素材选择与管理操作同时可用，增加搜索、筛选、24 项分页和媒体按需加载；读取失败保留旧数据并可重试。
- 总览优先展示待处理账号，统计可折叠；打开平台数据时清除其他账号详情选择。
- 普通隐藏管理页启用后台节流；扫码、编辑、消息、采集和登录检查受保护。网页区域仅在布局过渡期间轮询位置。
- 设置顶部展示当前版本、程序位置及实际数据目录。便携启动与安装版仍使用各自原有目录，避免未经迁移切换账号数据。

## 验证边界

已用实际账号服务、调度器和 SQLite 组合覆盖保活自身协调、延迟登录界面、恢复 URL 授权及任务并发。真实 Electron 两进程测试覆盖 Cookie 轮换、写盘、重启读取及诊断脱敏。

- 全量回归：主批次 194 个文件、5,154 项测试通过；独立 OAuth 流程 41 项通过，共 5,195 项。
- TypeScript、ESLint、生产构建、NSIS 安装包通过；打包使用本地已安装的相同 Electron 43.3.0 发行文件。
- 开发产物及最终打包程序均通过隔离桌面冒烟。覆盖 960/1120/1440/1920 像素布局、发布侧栏与原生网页区域分离、消息、数据观测和国际平台既有流程。
- 安装前完整备份并逐文件校验 35,433 个文件；安装后 80 个程序文件与打包产物哈希一致。
- 本机 15 个国内账号、2 个国外账号、1 个素材、46 条作品、9,839 条指标记录和全部浏览器资料目录均保留，数据库完整性通过。更新前备份已校验并在本机保留。
- 安装版已通过独立桌面启动入口重新打开，沿用原有实际数据目录。

真实平台的“新鲜扫码 → 正常退出 → 隔夜重开”需要经过实际时间验证。此次没有修改平台 Cookie 到期规则、清除真实登录环境或代替用户扫码。具体排查证据见[登录稳定性与体验排查](../登录稳定性与体验排查-20261012.md)。
