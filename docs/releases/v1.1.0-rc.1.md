# 1.1.0-rc.1 · 清新创作工作台

本轮升级了桌面界面、导航效率、连接状态与数据准确性。源码和独立的新构建位于项目目录；没有替换现有安装程序、迁移账号目录、重置 Cookie 或修改平台发布权限。

## 界面与便捷操作

- 雾蓝、淡紫、薄荷色主题，半透明卡片、柔和背景和统一圆角；保留深色主题与系统主题。
- AI 生成的海边创作工作室、云岛素材插画用于首页、素材、数据与发布模块。插画原图和完整提示词见 `src/renderer/assets/illustrations/README.md`。
- 首页增加创作横幅、继续创作、素材/发布/海外平台快捷入口、关键指标和数据覆盖板块。完整八项指标、今日变化、趋势与各平台明细继续保留。
- 首页、素材库和设置收起账号侧栏；创作者平台、数据和发布页面保留账号选择，减少无关占位。
- 顶栏搜索或 Ctrl/Cmd+K 打开命令面板：搜索页面、国内外账号、平台、昵称、账号 ID 与备注，支持多关键词、方向键、Enter、Escape 和焦点恢复。
- 模态框和文本输入中屏蔽会打断编辑的全局快捷键。原生平台浏览器获得焦点时，使用顶栏搜索入口。

## 连接与数据修复

- 并行网络刷新共用请求，保持准确忙碌状态，旧请求失败不覆盖新状态；主进程返回检查结束后的最新网络快照。
- 网络检测完成前显示「检查中」，不提前声称直连或代理已就绪。
- 设置读取/写入按顺序执行，防止主题和配置倒退；保存失败有提示。
- 海外账号首次列表与单账号修改合并，身份读取使用请求序号，防止旧响应覆盖。
- 国外数据页将加载中、确认无数据、失败区分；失败保留上次有效值，拒绝其他账号的数据，切换账号不显示上一账号的作品。
- 数字解析拒绝百分比、范围、带加号的不确定值、负数、小数计数与超出安全精度的整数；保留实测零和支持的单位格式。
- 作品分页结束时核对声明总数，并在去重后复核；未读全的任务保留结果并明确待复核，不冒报完成。
- 覆盖率区分未取得与确认零覆盖；无账号、未检测和读取失败均不会显示「全部正常」。
- 桌面桥接缺失时显示连接错误并停止数据页启动。仅明确的本地开发浏览器能使用带标识的演示数据，打包桌面不会回退假数据。

## 维护与验证

- 删除总览中未使用的样式与无效参数，提取可复用的插画模块；复用现有账号、采集、素材与发布 API。
- 打包排除已被编译进产物的重复 `node_modules`，`app.asar` 从 62,003,862 字节缩至 7,300,715 字节（约减少 88%，不含 Electron 自身体积）；构建阶段检查主进程和 preload 只外置 Electron/Node 内置模块，防止未来漏带运行依赖。
- 开发服务器不再监听安装产物、账号资料、备份和缓存目录，避免打包及浏览器写盘触发无关热刷新。
- `npm run typecheck`、`npm run lint`、`npm run build`。
- 全量单元/组件测试：205 个文件、5,289 项全部通过。报告：`output/ui-refresh/unit-tests.json`。
- `node scripts/electron-window-smoke.mjs --visual-refresh` 验证隔离空数据库、无虚构总数、插画加载、960/1024/1440 布局、明暗主题持久化、搜索键盘交互和页面侧栏规则。
- 冒烟临时数据和 Chromium 临时文件统一放在 `output/temp/`，退出前校验真实路径后清理。截图与报告位于 `output/ui-refresh/`。
- 精简后的已打包程序完成完整冒烟及视觉冒烟：账号工作区、网络 UI/IPC、凭据加密、国外授权边界、草稿流程、消息入口、八项基础指标和采集契约均通过；完整记录见 `output/ui-refresh/packaged-full-smoke.log`、`packaged-visual-smoke.log`。构建路径、测试数量和资源包哈希记录在 `output/ui-refresh/delivery.json`。

这些验证覆盖本地逻辑、界面和 IPC；没有对真实账号重新登录、在线采集或发布。真实平台的权限和接口变化仍以各账号的官方页面及实际采集结果为准。
