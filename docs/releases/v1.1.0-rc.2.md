# 1.1.0-rc.2 · 登录状态确认修复

创作者后台已返回当前账号的有效身份响应，但页面资源尚未全部加载时，旧版可能漏记后台登录确认；切换到管理页后也会持续显示无新主页观测导致的“待核实”。

- 带有当前身份、受限接口路径和 HTTP 2xx 的有效登录响应到达后立即记录后台登录，无需等待无关图片或 iframe 加载完成。登录页、验证页、错误页、缺少身份的响应仍不能确认登录。
- 用结构化 `retainedHomepage` 标记区分“管理页沿用已有主页结论”和“主页本次检查未得到结果”。前者保留在线状态及原观察时间，省略重复的待核实；后者与网络异常、安全验证提示继续显示。
- 后台独立显示“已登录 / 需要登录 / 尚未确认”，不以主页登录状态替代后台证据。
- 新增加载超过 30 秒、登录证据隔离、上下文标记读写与清除、检查时间保留、真实异常提示的回归测试。

构建：`release/login-status-1.1.0-rc.2/win-unpacked/`。验证与安装记录放在 `output/login-status-fix/`。现有账号数据目录与浏览器登录环境沿用。

验证：205 个测试文件、5,314 项测试全部通过；TypeScript、ESLint、生产构建通过。实际打包程序使用隔离测试目录完成完整冒烟，覆盖工作区、状态反馈、网络与 IPC、素材/草稿、消息入口和数据观测。报告见 `output/login-status-fix/unit-tests.json` 与 `packaged-smoke.log`。
