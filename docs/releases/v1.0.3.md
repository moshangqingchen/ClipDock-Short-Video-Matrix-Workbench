# ClipDock 短视频矩阵工作台 v1.0.3

更新日期：2026-09-14。适用于 Windows 10/11 x64。

## 视频号登录与网络恢复

- 修复登录页因连接通道失败、网络切换或超时未加载成功，仍被判定“未登录”的问题。页面加载错误只更新检查结果，保留原登录状态和账号资料。
- 登录页刚出现时先等待复核，避免重定向过程中的短暂页面状态立刻触发掉线通知；平台持续要求登录时仍会正常标记离线。
- 软件启动及网络恢复后，对曾经登录的视频号延迟、合并执行一次管理首页复核，沿用原账号分区。恢复期间再次断网会取消过时结果，不会清理 Cookie 或强行改成在线。
- 主动检查和定时保活可通过官方管理首页获取新身份结果。后台不会刷新正在使用的正常页面、隐藏的编辑页、扫码页或验证页。

## 保活计时

- 保活使用独立、持久化的任务记录计时，不再被每五分钟巡检的尝试时间不断推迟；重启后仍沿用该记录。
- 保活任务不再推迟正常的数据采集计划。
- 设置说明改为实际行为：定期检查身份，视频号在适当时机访问管理首页；登录有效期仍由平台决定。

## 下载与升级

- `ClipDock-1.0.3-setup.exe`：安装版。
- `ClipDock-1.0.3-portable.exe`：免安装版。
- `SHA256SUMS.txt`：安装包校验值。

升级保留原账号和浏览器登录环境。自动维护使用经过桌面独立启动验证的工具，避免 Codex 子进程读取隔离数据目录。正常使用桌面快捷方式即可。

## 验证范围与限制

已增加加载失败、网络恢复、重复恢复、运行中巡检合并、再次断网、活动页面保护、真实掉线复核及保活跨重启计时的回归测试。

验证结果：175 个测试文件、4653 项测试全部通过；TypeScript 类型检查、ESLint、生产构建和 Windows 打包版冒烟测试通过。打包验证使用独立临时数据，覆盖账号 IPC、网络分流、登录凭据加密、编辑器和四种窗口尺寸。

本次修复软件误判和调度问题，不承诺平台会话永不过期。若当前连接通道仍失败，显示待复核；若微信官方后台真正要求重新扫码，仍需用户完成登录。
