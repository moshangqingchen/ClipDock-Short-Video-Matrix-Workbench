# 1.0.6-rc.5

修复抖音精选页面登录成功后，账号列表仍保留“未登录”的问题。

当前抖音顶栏的个人头像链接使用 `/user/self`，头像可能以 CSS 背景呈现。旧规则只接受带具体账号标识的链接和 `img` 元素，因此没有得到新的在线结论，列表继续显示此前的未登录状态。

新规则识别顶栏个人主页链接内的可见头像，兼容图片与背景图片。读取范围限定在当前官方页面的顶栏，排除推荐内容、视频作者、左侧通用“我的”入口、占位头像、隐藏节点、外站链接和多个不同头像。页面尚在加载或同时出现登录入口时，继续等待明确结果。

识别过程只读取已加载页面，不额外发起登录请求，不读取 Cookie、账号标识或二维码令牌，不改变账号分区。

登录识别、状态检测、账号服务与状态组件共 4 个测试文件、307 项测试通过；类型检查、ESLint、生产构建和安装包隔离启动烟测通过。

安装后使用原有账号分区复测：无需重新扫码，已登录的抖音精选页面被识别为在线，侧栏与顶部状态同步更新。升级前已完成数据备份，升级后账号、作品、历史指标及浏览器分区保留检查通过。
