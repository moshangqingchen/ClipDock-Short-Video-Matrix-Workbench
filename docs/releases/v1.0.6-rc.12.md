# 1.0.6-rc.12

修复 rc.11 引入的账号列表文字重叠。详细登录状态组件默认允许换行，侧栏旧样式又给其所有嵌套 span 叠加间距；多账号、粉丝数和待复核状态同时出现时，内容超过固定 40px 行高，挤到相邻账号。

- 侧栏恢复为“昵称与位置 / 登录状态与粉丝数”两行；本次检查说明保留在悬浮提示和主页面详细状态栏。
- 只允许详细状态栏换行，紧凑状态保持单行。
- 收窄侧栏和顶部身份区的 CSS 选择器，避免影响嵌套状态圆点、文字；明确元信息行高。
- 长昵称和粉丝数在各自区域内省略，不遮挡相邻账号和更多操作按钮。

修复范围仅为展示样式及组件呈现，没有修改账号、登录检测或连接逻辑。上一版的单账号布局检查未覆盖相邻多账号及双状态组合；本次增加独立真实 Electron 排版回归。

验证：相关组件 39 项测试、TypeScript、ESLint、生产构建和 NSIS 打包通过。`scripts/sidebar-layout-smoke.mjs` 使用真实组件和生产 CSS，在 15 个合成账号、960/1120/1440/1920 像素窗口、100%/125% 缩放下，逐项检查文字实际边界。旧版 8 组均检出重叠或越界，修复版 8 组均为零；本机对照报告和截图位于 `output/sidebar-fix/`。

本机已正常退出后更新安装版，80 个程序文件与构建产物一致；15 个国内账号、2 个国外账号、46 条作品、9,869 条指标记录及浏览器目录保留，数据库完整性通过。重新打开安装版并查看实际账号列表，昵称、状态和粉丝数已恢复为两行，不再与相邻账号重叠。更新前备份已校验并在本机保留。
