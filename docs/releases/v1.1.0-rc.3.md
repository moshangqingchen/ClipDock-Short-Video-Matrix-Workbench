# 1.1.0-rc.3 · 登录状态显示修复

修复已登录创作者后台仍显示“尚未确认”的问题。主进程此前已保存后台登录证据，但传给界面的账号 DTO 白名单遗漏了确认字段；现在完整传递主页与后台各自的状态、原观察时间，以及沿用主页结果的标记。

- 保持主页和创作者后台的登录判断独立。只输出经过校验的结论与时间，不传递原始身份响应或附带内部字段。
- 管理页沿用已确认的主页结论时不再重复显示“待核实”；主页检查无结果、网络异常与安全验证仍显示真实提示。
- 延续 rc.2 的修复：当前后台已返回有效身份响应时，即使页面图片或 iframe 仍在加载，也能记录后台已登录。
- 增加真实 DTO 到界面的回归测试，以及打包程序中经数据库、仓库、IPC 和预加载桥读取登录证据的冒烟检查。

构建目录：`release/login-status-1.1.0-rc.3/win-unpacked/`。
测试、覆盖安装及原数据校验记录：`output/login-status-fix/rc3/`。
沿用现有账号数据目录与浏览器登录环境。

验证：206 个测试文件、5,335 项测试全部通过；TypeScript、ESLint、生产构建通过。打包程序完整冒烟通过，包含真实账号 IPC 登录证据回归，以及工作区、网络、消息入口和数据观测检查。测试使用项目内隔离目录。
