# ClipDock 短视频矩阵工作台 v1.0.1

更新日期：2026-09-12。适用于 Windows 10/11 x64。

## 下载与升级

- `短视频矩阵工作台-1.0.1-setup.exe`：安装版，推荐日常使用。
- `短视频矩阵工作台-1.0.1-portable.exe`：免安装版。
- `SHA256SUMS.txt`：下载文件的 SHA256 校验值。

升级前请退出工作台并备份原数据目录。沿用原运行方式和数据目录，不要删除账号浏览器分区；本版无需主动重置登录环境。应用尚未签名，Windows 可能显示“未知发布者”。

## 本次更新（相较 v1.0.0）

### 国内与海外平台同窗管理

- 创作者平台入口统一管理国内六个平台与 YouTube、TikTok、X，增加平台分类、筛选及独立网页账号环境。
- 海外平台以官方网页入口为主，官方 API 作为可选功能；网页登录与 API 授权分别显示。
- 增加海外应用配置、OAuth 授权、Token 加密存储与按需刷新、取消授权和本机快照。
- 增加可取消的官方数据读取任务；网络条件不满足时等待，恢复后重新检查。
- 接入 TikTok 草稿上传和 YouTube 可恢复上传。TikTok 仍需用户在平台确认发布；YouTube 默认私密。

### 网络分流与多账号稳定性

- VPN 规则模式支持国内平台 DIRECT 与海外代理同时使用；关闭代理后国内继续直连。
- 国内连接按账号隔离，逐条核验实际路由及代理内核归属；网络或规则变化时重新检查。
- 使用 Windows 原生 TCP 表查询，减少多账号并发时控制器归属检查超时。
- 国内规则模式不再依赖每 15 秒访问一次 IP 查询网站；网络休眠保留 Cookie 和已有登录结论。

### 登录识别、作品与媒体展示

- 完善主页登录、账号身份识别及会话保留，增加相关平台采集与回归测试。
- 改进采集任务队列、状态反馈、作品列表和账号工作区。
- 增加远程媒体授权、格式校验和本机缓存，改进头像与作品封面展示。
- 抖音封面优先选择平台提供的 PNG/JPEG 候选，避免部分 WebP 图片无法被解码的问题。
- 作品入口关联所属账号环境，支持从作品列表打开对应作品页。

### 桌面体验与维护

- 增加系统托盘支持，调整侧栏、设置页及工作区界面。
- 清理与项目无关的演示页面，排除临时诊断输出、截图与本机工具记录。

## 已知问题与验证范围

- 海外官方 API、TikTok 草稿及 YouTube 上传尚未完成真实平台端到端验收；需要用户自己的开发者应用、权限与可用网络。X 上传和平台侧远端撤销尚未开放。
- 部分抖音及视频号作品封面仍可能缺失，本版不承诺全部恢复。
- 生产构建与 TypeScript 检查通过。
- 全量测试 4637 项中 4636 项通过。`exclusive-business.integration.test.ts` 中恢复排队账号的测试失败，单独重跑仍失败，尚未修复。
- ESLint 仍有 5 个错误（控制字符正则规则）和 4 个警告，未将本次验证标注为全部通过。
