# 1.0.6-rc.6

六个平台的数据观测页面原先只展示部分指标；接口失败没有明确恢复入口，缺少采样的趋势可能被补零或沿用旧值。本版补齐基础指标查看，并保留未知值、采集范围和数据来源。

## 查看数据

- 总览、平台账号表、账号详情和浏览器数据面板展示粉丝、关注、获赞、评论、播放、分享、收藏、作品八项指标。总览和详情可切换任一指标查看趋势。
- 作品明细展示播放、获赞、评论、分享、收藏及字段更新时间、来源。已采作品的合计与账号总量分开，显示有值作品数量；本页排名不代表全部作品排名。
- 平台和详情显示最近采集状态、失败或部分完成原因、写入数量和时间。读取失败可重试，已取得的另一部分仍可查看。
- 账号详情的经营分析可查看完播率、平均观看时长、内容收益、粉丝画像和流量来源。点击“启用并打开官方分析页”，待页面展示对应数据后返回读取；日期、单位、收益结算状态和账号归属必须明确。经营记录逐批展开，避免大量记录一次渲染。

## 数据准确性与性能

- 未采集日期不补零、不沿用旧值；缺少对照历史时不制造日/周/月增量。汇总显示有值账号数，真实零值保留。
- 账号概览和全部已采作品分别统计；未读到作品不意味着该账号没有作品，也不会清空已有作品。
- B 站仅在业务成功且明确总数为零时兼容空列表的特殊返回。六平台的明确业务失败不会因响应包含列表字段而被误认为成功。
- 已确认的当前会话资料可补充缺失概览字段；页面读取只接受可见、明确的累计指标，区间数据不作为累计总量。
- 总览采用批量数据库查询，页面通知合并刷新；指标与作品分页独立读取，避免翻页重新查询账号历史。等待有上限，过时响应不会覆盖新账号。
- 失败诊断仅保存白名单端点路径、有限数值业务码和白名单字段类型，不记录 Cookie、令牌、查询参数或原始响应。

## 使用范围

适用于抖音、快手、小红书、哔哩哔哩、百度百家号、微信视频号。基础数据继续使用各账号自身登录会话和现有请求；没有增加采集接口或放宽网络校验。沿用队列去重、并发上限、同平台串行及限流退避。

“指标入口齐全”不表示平台为每个账号提供所有指标。权限不足、官方页面未提供、日期或统计口径不明确时会保留缺失状态；不会生成假数据。经营指标来自用户打开的官方分析页面，不保证补齐未曾观测的历史；实际可用字段须以各账号后台返回为准。

## 验证

- 类型检查、生产构建及 ESLint 通过。
- 189 个测试文件、4,917 项测试分批通过：稳定批次 188 个文件、4,876 项，OAuth 流程单独 41 项。一次混合执行曾出现 OAuth 测试工作进程异常退出；该文件单独及与相邻测试组合复测通过，尚未确定该异常的根因。

- 真实安装升级前完成程序与用户数据备份、逐文件校验，升级后数据库完整性及账号、作品、历史快照、浏览器配置保留校验通过。平台实际可用数据仍以各账号采集结果为准。
