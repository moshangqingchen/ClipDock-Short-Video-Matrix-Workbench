# ClipDock 短视频矩阵工作台 v1.0.5

更新日期：2026-09-14。适用于 Windows 10/11 x64。

## 备份恢复与素材保护

- 修复恢复备份后删除素材可能删除其他本机文件的问题。恢复时丢弃旧缩略图缓存路径；删除素材只清理该素材在本机生成的缓存，保留原素材文件。恢复后的预览使用原素材引用。
- 修复合并备份使国外账号超过 30 个后，账号列表与备份导出无法使用的问题。导入前检查合并后的账号总数，超限则拒绝导入并保留现有数据；相同账号 ID 不重复计数。
- 修复旧备份覆盖较新国外统计快照的问题。合并时补充历史记录，当前快照按采集时间保留较新的数据。

## 下载与升级

- `ClipDock-1.0.5-setup.exe`：安装版。
- `ClipDock-1.0.5-portable.exe`：免安装版。
- `SHA256SUMS.txt`：校验值。

覆盖升级保留账号、素材引用及浏览器登录环境。升级前建议正常退出工作台并备份数据。
