# ClipDock 短视频矩阵工作台 v1.0.2

更新日期：2026-09-12。适用于 Windows 10/11 x64。

## 下载与升级

- `ClipDock-1.0.2-setup.exe`：安装版，推荐日常使用。
- `ClipDock-1.0.2-portable.exe`：免安装版。
- `SHA256SUMS.txt`：下载文件的 SHA256 校验值。

升级前请退出工作台并备份原数据目录，沿用原运行方式和数据目录，无需重置账号登录环境。应用尚未签名，Windows 可能显示“未知发布者”。

## 相较 v1.0.1 的修复

- 修复网络恢复集成测试缺少账号身份信息接口的问题。补齐测试环境后，原有“仅恢复在线／即将过期账号”检查通过；未跳过测试或放宽实际登录校验。
- 修复 5 个控制字符正则相关 lint 错误：改用等价的字符编码检查，保留头像、媒体地址、作品链接及出口位置文本原有过滤范围。
- 清理类型导入及未使用的类型，消除 4 个 lint 警告。
- 安装包版本升级至 1.0.2，包含上述源码修复。
