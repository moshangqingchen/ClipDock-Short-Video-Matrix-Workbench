# 1.0.6-rc.7

修正主页未登录但账号列表显示在线的问题，并增加账号工具栏的“消息”入口。

## 登录状态

- 抖音、快手、小红书、B 站以主页当前账号的明确登录状态为依据，创作者后台登录、历史在线记录和 Cookie 存在本身不再证明主页在线。
- 主页明确未登录立即更新；主页未加载、识别不完整、会话变化或重启后尚未复核时显示待核实，保留登录环境和账号资料。
- 管理页面可短时沿用本进程最近确认的主页结论，最长五分钟；届时复核，不自动跳走用户页面。
- 补充快手新版侧栏“立即登录”入口识别。无独立主页的平台仍检查自身管理页面。

## 消息

打开账号后点击顶部“消息”。使用该账号独立浏览器环境内的官方消息界面，平台提供的会话列表、对话和回复输入框均由官方页面承载。用户自己输入并点击发送；应用没有自动回复、群发或独立的私信发送接口。

| 平台 | 入口与范围 |
| --- | --- |
| B 站 | 直接打开官方消息中心的“我的消息”，可在会话列表选择联系人并在对话框回复；发送资格由平台处理。 |
| 抖音 | 保留当前主页，尝试打开唯一可见的顶部“消息”。入口尚未加载或布局未识别时，可重试或手动点击页面的“消息”。 |
| 小红书 | 打开官方私信通，按官方页面登录并取得相应私信或客服权限；不保证普通账号全部适用，也不保证与创作者中心共享一次登录。 |
| 微信视频号 | 打开视频号助手，按提示进入“互动管理 → 私信”；菜单是否出现取决于账号权限。 |
| 快手、百家号 | 在官方后台核验消息入口及账号权限，尚不承诺普通账号网页私信收发；未提供网页入口时需使用平台客户端。评论、系统通知不会被当成私信。 |

消息模式持续保护当前原生页面：切换账号或隐藏页面后不自动回收，后台采集、保活和迟到导航不能覆盖对话。选择主页、管理、地址导航、历史导航或“离开消息”后解除保护。网络撤销、账号重置和应用退出仍会关闭页面；未发送草稿是否持久保存由官方页面决定，应用不另存聊天内容。

## 官方入口核验

- [B 站消息中心](https://message.bilibili.com/#/whisper)：[该页面引用的前端脚本](https://s1.hdslb.com/bfs/static/2233-monorepo/message-pc/static/js/index.f2b7bca0.js)包含 hash `whisper` 路由、会话列表和聊天窗口。
- [小红书私信通](https://sxt.xiaohongshu.com/im/login)：需按页面提示登录和取得对应权限。
- [视频号助手](https://channels.weixin.qq.com/platform)：[该页面引用的前端脚本](https://res.wx.qq.com/t/wx_fed/finder/helper/finder-helper-web/res/static/js/index.dd23013a.js)中的私信菜单受账号权限控制。
- [快手创作者服务平台](https://cp.kuaishou.com/profile)：[该页面引用的前端脚本](https://p66-plat.wskwai.com/kos/nlav11104/static/ks-cp/js/cp.63021c43.js)存在“私信”入口逻辑，但不足以证明每个账号均能双向收发。

上述核验于 2026-09-28 完成。消息不通过工作台 IPC 传递，测试不向真实联系人发送消息。
