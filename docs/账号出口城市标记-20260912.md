# 账号出口城市标记

国内账号名称旁显示地图标记和出口 IP 归属城市，悬停可查看 IP、完整归属地和检测时间。城市缺失时降为省份或国家；查询失败显示“位置未知”。提示注明“IP归属地估测，可能与平台显示不同”。

位置仅在内存中用于显示，不写账号数据库、不影响登录状态或业务联网许可、不修改 VPN 或系统代理。账号只有在当前网络代次允许联网时才显示；规则模式还要求该账号当前连接池曾成功验证实际 DIRECT 连接，不把其它账号或匿名诊断连接当作该账号的连接记录。

规则模式用独立匿名 CONNECT、TLS、Windows 内核归属与实际 DIRECT 核验访问固定 IPIP 地址；代理关闭时，在已确认的直连网络上下文中使用固定匿名 HTTPS 请求。请求不带账号 Cookie。城市来自 IPIP 返回的地域信息，不使用节点名称、目标服务器 IP、账号资料或 Cloudflare 机房编号推算。

同一网络缓存十分钟，失败六十秒后再测；切换网络、规则、内核或配置后清掉旧位置。所有在途结果核对原上下文，过时结果不会写回。
