# 路径资格的运行时组合

2026-09-08。本记录说明新增的主进程组合代码，不把模块测试或历史报告当成真实出网许可。

`ObservedPathQualificationProducer` 接收明确的主进程工厂/解析策略审查，以及 `AnonymousPhysicalRouteCollector`。没有审查时立即返回不可用，不创建匿名请求。审查必须明确当前 Electron/启动 TCP 约束、各 origin 的所有可能地址族、跨工厂适用范围和有效期限；组合器不自行添加 IPv4 限制、工厂等价或大陆出口结论。

每个可能地址族只选一个已审查的代表目标进行双流观察，不按每个 URL 或每轮续证重复采集 socket。收集器保留真实 DNS、请求图、应用与内核 socket、前后配置关联，以及精确关闭自身连接后的存活对照。缺少其中任一必要事实，本次准备不产生资格。HTTP 204 只记录控制器响应，不能代替 socket 消失证据。

不同地址族可能在不同时间完成。`resolver.observationContexts` 因此为每组原映射保留自己的输入和主进程原始关联对象，最终一次真实 postflight 输入作为资格的参照。适配器要求这些组属于同一配置、规则、加载来源、进程生命周期、OS 网络和 hosts 环境，并精确覆盖全部映射；没有重复、遗漏或额外映射。原请求和 DNS 时间不重写，旧 JSON 不能恢复内存来源标记。

跨工厂 resolver 等价只能引用本次实际观察，再结合明确的工厂代码审查。物理路径对其它工厂的适用范围也须有独立审查，不能由同一个进程名或 PID 推导。组合器保留原物理样本，以审查给定的期限建立资格；每次使用仍由现有 Source 核对新鲜的实际目标、DNS、规则和当前源地址条件路由。资格不是 Gate 许可，也不包含“大陆直连为真”的快捷标记。

准备完成后仍等待所有底层清理，随后重新核对信号、规则代际、审查内容和时间。等待清理期间审查撤销、版本变化、到期或时钟异常都返回不可用；清理结果不确定则保留停用状态。`PathQualificationLifecycle` 只保留原始对象，撤销同步清空，getter 不隐式发起探测。

验证使用真实组合器、双流收集器、请求图解析器和原关联/映射校验器，底层 OS 与 HTTP 为受控替身。正例验证较早的请求观察和较晚的 postflight 可以合法组合；反例覆盖 JSON 恢复、错误物理观察、缺少审查或地址族、真实清理未结束、撤销和过期。诊断目录缺项的复现已修复，错误目录在任何双流采集前拒绝。生产运行时、默认组件、组合器和生命周期四模块已纳入 09:16 全量 2710 项回归；新地址族投影还覆盖原资格、启动约束及当前选择失效。它不是公网资格验收。

准备后的 getter 还会同步复核当前主进程审查。原始对象与审查内容绑定在内存 WeakMap，撤回审查、修改内容、同 ID 替换、过期、抛错或递归读取都不能复用旧结果；不读取历史报告，不重新准备或延长期限。默认组件在旧适配器清理后、采样前和结果返回前再次复核；迟到结果不能在撤审后恢复资格。实际准备入口及其空闲窗口条件见[运行时接线](./network-proof-source-runtime.md)。
