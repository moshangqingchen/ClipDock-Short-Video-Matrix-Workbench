# 启动网络检测提速（2026-09-10）

网络指纹的首次确认和变更恢复，改为在原有 1 秒稳定窗口结束后进行第二次读取；状态稳定后仍每 5 秒检查一次。仍要求两次相同观测，失败或变化立即撤销可用状态。

Windows 网络状态变化或恢复后，立即撤销旧权限，等待取消中的系统读取真正结束，再触发新的代理检测，不再等下一个 5 秒定时周期。重复事件合并，停止运行或更新的 TUN 开启观测会取消排队的重查。

系统代理或 PAC 已明确开启时，连续两遍确认开关后即可返回开启状态，省去网卡和路由枚举。关闭代理仍要求完整的系统和隧道检查。未验证的启动国内模式只用于界面显示。

## 本机测量

`node scripts/network-startup-benchmark.mjs` 使用真实的 Windows 只读检测器和互斥切换器，不修改代理设置，也不请求平台网站。该测试记录初次模式判定，以及网络指纹确认后重新完成模式判定的时间；不包含整个 Electron 界面启动，也不包含 Clash 控制器的提前通知路径。

当前代理开启环境下，一次前后对照：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 初次模式判定 | 1.575 秒 | 1.576 秒 |
| 网络确认后的稳定判定 | 11.532 秒 | 4.201 秒 |

稳定判定耗时减少约 64%。这是单次本机测量，不是所有网络环境的保证；国内模式尚未进行真实关闭代理的对照测试。原始记录见 `network-startup-before.json` 和 `network-startup-after.json`。

验证：Windows 指纹、代理读取、互斥切换、渲染层网络状态和面板共 128 项测试通过，包括取消后的延迟结果、重复变更合并、停止后不重启检测、新 TUN 观测优先和两次一致性确认。
