# 国际隧道读取与授权

2026-09-08。`GlobalProxyRuntime` 已在主进程组合匿名出口探针、`ProxyTunnelReader`、`ProxyTunnelAuthorizer` 与 `ProxyTransport`，供主动点击的官方授权入口使用。启动和显示国际账号卡不会自动发起 OAuth 或国际出口采样。当前没有真实开发者应用，尚未验收平台授权、数据读取或上传。

## 读取范围

读取器固定使用显式 `127.0.0.1` 或 `::1` 的 HTTP 控制地址和 mixed 端口；不采用系统代理、环境代理、域名解析或重定向。一次读取先确认当前控制器配置，再取得控制端口的 Windows 进程身份及 `/connections`、`/proxies`；mixed 端口归属从这次 CONNECT 的反向 Established socket 核对，最后复核配置及代际。

控制器监听仍要求明确的地址族覆盖。mixed 端口仅显示 `::` 时，不据此推断 IPv4 可用：生产 `WindowsTcpSocketReader` 按控制器 PID 和 CONNECT 客户端地址／端口读取已接受的连接，要求唯一反向四元组、Established 状态和相同 PID／进程出生时间／可执行文件身份。证据保留原始时间、查询范围摘要及 socket 快照，不伪造监听证据。通用 Windows 读取器和控制器监听规则没有放宽。

当前连接按调用方持有的 socket 源地址／端口裁剪，同源冲突记录仍保留给授权器判断；代理策略只保留这批连接引用的链条。原始响应有大小、时间和结构限制，不进入日志、IPC 或备份。控制器密钥从主进程注入，只用于本机请求。

公开取消结果可以先返回拒绝，但真实工作槽位持续占用到 HTTP、Windows 读取及各层 Promise 完成清理。`whenIdle()` 等待真实资源关闭，清理失败后拒绝再用。原生 TCP 查询没有 Abort API，其原 Promise 仍留在清理屏障中。每个读取器只有一个并发槽；生产 Runtime 分别为匿名出口和国际业务创建读取器，让续证不必等待长业务请求结束。业务仍串行，整体工作上限 8 项，业务不能占满给证据保留的槽位。`ClashReader` 的 GET 清理也纳入这一等待契约。

## 授权范围

授权器核对本次 `ProxyTunnelContext` 的官方平台目标、443 端口、完整 socket 上下文、实际 HTTPS/TCP 连接、控制器及 mixed 端口的同一内核进程身份。配置指纹、规则／设置代际和读取时间必须对应；记录歧义、DIRECT／REJECT 或未知代理类型均不能放行。

国际资格还必须包含当期匿名出口样本：原始观察时间、允许国家及实际代理链摘要。样本链与业务连接的有序链条和 API 可见策略摘要需一致；单纯“代理端口可连接”“海外网站能打开”或公开 UI 状态不能签发许可。授权租约默认 5 秒，证据默认最长 15 秒、读取默认 10 秒。持续连接通过下述续证更换短许可，不直接延长旧证据。

许可过期、设置或网络代际变化及调用方取消都会撤销。传输层在 TLS 与业务头／正文发出前核验 CONNECT 连接，禁止回落直连。一次[真实匿名时序观察](global-proxy-context.20260908T055121301Z.md)确认当前内核和 Google Token host 在 TLS 前有唯一连接记录；仅发 CONNECT 和 TLS，没有平台 HTTP 或凭据，不能外推其他目标或配置。

## 已接入的生产入口

1. `GlobalProxyRuntime` 仅在系统互斥状态确认代理开启、OS 网络快照有效且本机配置合法时按需取证。配置和加密控制器凭据摘要、网络代际均留在主进程；历史报告或 renderer 状态不能恢复许可。
2. [匿名探针](proxy-egress-probe.md)固定经过 CONNECT → 默认验证的 TLS → 同连接证据核验一次 → Cloudflare 公开 trace 请求。无 Cookie／Token／客户端证书。此匿名 TLS 时序不改变业务 `ProxyTransport` 的 TLS 前门闩。
3. 有效非大陆样本、进程身份、控制器指纹和代理链摘要形成短期资格，保留原始过期时间。授权期间才能续证；设置、OS、挂起、账号清除和退出均接入撤销。退出用 `allSettled` 等待 OAuth 与代理资源实际清理完毕。
4. 开始／查询／取消 IPC 只投影账号 ID、平台、事务 ID、阶段和固定错误码。缺应用配置时，在打开浏览器和采样之前拒绝；配置完成也不跳过链路核验。

首次取证尚未发布资格时，控制器失联或已知指纹变化也会同步撤销；迟到样本不得发布旧资格。旧的失联记录可以被后续完整的新取证消解，同轮的新观察必须与样本一致。续证按本轮实际采样耗时加 250 ms 裕量提前安排，仍以原证据期限为准；如果来不及完成，原许可到期即关闭。重复缓存期限不推进时，不自动密集续读或延长许可。

真实应用授权与 API 权限验收尚未发生；用户当前无开发者应用，系统代理和 TUN 按用户要求保持现状。

## 持续连接续证（2026-09-08）

主进程授权器只接受自己签发、仍有效且尚未释放的旧许可。续证复用原始传输上下文和连接建立时间，重新核对同一内核连接 ID、四元组、目标、进程归属、配置、代理链与当期匿名出口。连接年龄可超过首次签发期限，但新证据的读取时间和有效期不放宽；匿名诊断没有这种续期入口。

续证必须在旧许可仍有效时完成，签发一个到期时间确实推进的新对象。传输层检查代际相同、信号独立和两个许可的连续有效性，换好监听器后才释放旧对象。默认按剩余期限和实测核验耗时提前读取，每轮保持单个在途核验；不重连、不重发已发送的业务，也不使用旧连接记录充当本轮结果。

失败、DIRECT、连接 ID 改变、超时、网络／配置变化和取消都结束当前隧道。旧许可在续证期间到期时立即终止；晚到许可只做释放，不能恢复连接或提交成功。响应已经结束而核验依赖未真正退出时，仍占用清理槽位，防止后续请求撞上尚未清理的读取器。

这项改动是上传的前置基础。当前请求总超时默认仍为 15 秒，最大构造上限 120 秒，正文仍有大小限制；没有开放 TikTok 动态上传地址、分片上传、发布或自动重试。正式大文件流程和三平台实际权限仍待实现与验收。
