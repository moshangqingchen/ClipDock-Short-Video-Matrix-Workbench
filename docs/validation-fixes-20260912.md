# v1.0.1 发布后代码检查修复

## 原因与修改

- 网络恢复集成测试的原生 ViewPool 替身缺少 `getIdentityEvidence`。快手采集已要求该接口返回新鲜的登录身份信息，因此在测试中提前失败。补齐原生身份观测替身，并按账号状态和页面是否已加载返回结果；保留真实调度器、网络权限及原有“只恢复在线／即将过期账号”的断言，不延长等待时间、不跳过测试、不放宽生产登录校验。
- 将头像、媒体地址、作品链接和出口位置解析中的控制字符正则改成等价的字符编码检查，保留原有拒绝范围，以及位置文本允许 CR/LF、媒体地址拒绝空格的差异。
- 将内联类型导入改为显式类型导入，移除未使用的类型导入。

## 修复后验证

- 相关 6 个测试文件、168 项测试通过。
- 全量 175 个测试文件、4637 项测试全部通过。
- `npm run lint`：0 错误、0 警告。
- `npm run build`：TypeScript 检查、Vite 和 Electron 生产构建通过；仍有前端打包体积提示。
