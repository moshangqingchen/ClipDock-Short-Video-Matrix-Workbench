## 真实环境验证边界

### 用户截图反馈后的补充修复（2026-09-10）

用户再次提供的截图确认 Chrome 灰色外框仍覆盖软件功能栏。此前网页宽高、导航和历史检查通过，只能证明网页尺寸正确，不能证明 Windows 非客户区和外框没有越界；此前的视觉验收不足。

修复在 Electron 内创建实际的原生子容器，将 Chrome 主窗口作为其子窗口，并按 UIA／原生渲染区域动态定位。子容器边界负责限制合成绘制；仍保留 Chrome 原始框架样式，以免内部布局误算。裁剪区域在显示、缩放后重新核对，菜单遮挡时隐藏整个容器。原型曾使用被动静态容器，实测出现能点击、不能输入；已改为专用窗口过程，在网页左键点击后激活 Chrome 并将原生焦点交给其渲染窗口。只处理本账号子窗口，隐藏或退出后不再交接焦点；退出时解除输入线程关联。相关接口依据 [Microsoft SetFocus 说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setfocus)。
