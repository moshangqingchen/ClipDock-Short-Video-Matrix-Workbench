# 国外网页数据观测

2026-09-10：国外账号的「数据观测」默认进入完整网页数据看板。无需开发者应用或 API 授权；登录官方后台后点击「立即采集」。采集时临时显示该账号的官方页面，读取结束后返回看板。窄窗口卡片自动排成两列或三列。

## 已实现

- YouTube Studio：频道总览 / 分析页面的当前订阅者、观看次数、观看时长（小时）、展示次数，以及页面展示的点赞、评论、分享和明确标注的视频数量。
- TikTok Studio：总览 / 分析页面的粉丝、观看、点赞、评论、分享、主页浏览。
- X：账号分析页面的展示、互动、粉丝、浏览、点赞、评论、分享及主页访问；是否展示仍取决于平台权限和当前页面。
- 支持这些指标的中英文标签，保留原始显示值，例如 `1.2K`、`1.2万`，不推算为精确整数。
- 按账号保存最后一次非空网页快照，展示来源页面、读取时间、浏览器来源和可识别的日期选择。空读和失败保留旧快照并明确说明；缺失数据显示「—」，不会写成零。
- 新增按账号、日期、页面及页面统计周期保存的历史记录，上限 1000 条。7／30／90 天筛选本机采集记录，不会修改官网时间选择。趋势只比较同一账号、页面与统计口径，每天保留最后一次有效采集；无数据的日期不补零。展示单位换算只用于绘图，卡片及图表提示保留官网原值。
- 全屏指标卡片、可切换指标的趋势图、采集历史和成功反馈。修复打开看板后点击官网快捷入口没有回到网页的问题。界面文字从「Chrome 试用」改为「使用 Chrome」，不是付费试用或到期限制。
- 官方 API 单独放在「官方 API（可选）」页签，原有资料、指标、作品读取继续使用其独立授权机制。

## 实现边界

本次是当前官方页面的只读指标汇总，不是遍历全部作品或无人值守抓取。没有识别出来的标签、图表、权限受限数据和页面未加载的数据不做推断。重复标签对应不同数值时不采纳，以免把不同表格行或统计时间合并。

内置浏览器读取渲染后的 DOM 文本，排除输入框、可编辑内容、隐藏内容等。Chrome 使用 Windows UI Automation 读取应用独立账号窗口里的文档文本，开启辅助功能树；校验已提交的文档地址属于对应平台数据页，读取前后保持同一文档地址。地址栏可能省略协议或包含未提交输入，因此不再用地址栏文本判断数据页；频道快捷入口也改为读取真实文档地址。不会使用 Chrome 调试端口、注入 Chrome 网页脚本或复制 Cookie。

API 授权状态、原有 Cookie、用户日常 Chrome 配置与网页快照分别管理。数据库迁移 12 新增 `global_web_observations`，迁移 13 新增 `global_web_observation_history` 并导入既有快照。只保存筛选后的数值和来源，不保存原始网页文本、URL 查询参数。删除账号级联删除其快照和历史。读取前后验证账号及网络生命周期，切换浏览器或撤销代理时丢弃迟到结果。
