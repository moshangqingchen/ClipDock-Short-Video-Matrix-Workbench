# 代理开关简化修复

2026-09-10，按用户明确的新要求替代规则双通路方案。

> 历史记录：2026-09-12 用户重新要求 VPN 规则模式下国内外同时使用，最新实现见[规则模式国内外同时使用](规则模式国内外同时使用-20260912.md)。

## 当前行为

- 关闭系统代理和 TUN：国内平台启用，国外官网休眠。
- 开启系统代理或 TUN：国内平台休眠，国外官网可在软件内打开。规则模式和全局模式使用同一条切换规则。
- 代理客户端窗口是否打开不作为开关依据。Windows「自动检测设置」本身不算代理开启。
- 国内和国外账号继续使用各自的持久 Session。切换会关闭旧页面和连接，保留 Cookie、LocalStorage 与账号记录；恢复不自动重复发布。
- 代理状态读取失败时显示「检查中」，下一次有效检测自动恢复。国内启动不再依赖 IP 查询网站、出口国家验证或控制器在线。
- 海外官网使用 Electron 系统代理，遵循用户的系统代理/TUN配置；官网浏览不再依赖 CONNECT 转发和逐连接验证。官方 API 授权功能仍独立。

## 已确认的原因与修复

1. 上一版国内规则通路依赖短时有效的出口/连接验证，页面资源请求和续检导致反复撤销。生产入口改为单一互斥开关。
2. 控制器关闭/不可读曾被转换为「无法确认代理关闭」，阻止正常国内使用。改为直接读取 Windows 代理设置及活动隧道。
3. 本机实际使用的「Meta Tunnel」未在已识别隧道名称中，曾返回 unknown；补充识别后，本机读取结果为 active / ACTIVE_TUNNEL。
4. Electron 销毁视图时可能清空 `view.webContents`。ViewPool 现在保存稳定引用，关闭后不再从已清空属性取对象。
5. 国内 show 请求可能在组件卸载后完成，盖住国外页面。增加显示操作顺序与取消后的隐藏收尾。
6. 海外主文档加载失败不再吞掉错误留下白页，改为释放页面并显示可重试错误；子资源失败和导航取消不误关闭页面。

启用仅表示软件允许该侧运行，实际访问和账号登录仍以官网返回结果为准。未进行实际账号登录或发布。
