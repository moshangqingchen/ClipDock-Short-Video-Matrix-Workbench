# 国外账号工作区调整

本轮按五张界面截图统一账号添加、官网工作区和平台范围切换，保留现有代理开关行为及独立账号 Session。

## 交互

- 侧栏标题下拉选择「国内短视频平台 / 国外短视频平台」，不再占用网页区域显示两枚切换按钮。
- 国外账号通过弹窗添加：YouTube、TikTok、X 平台卡片，选填账号名称，点击「创建环境并去登录」。名称为空时使用已有默认命名逻辑。
- 创建账号成功后选择该账号；代理已开启时自动在软件内打开官网。未开启代理或官网加载失败时保留已创建账号，在原账号下重试，不重复添加。
- 默认页面仅显示选中账号的官网工作区；顶部集中主页、管理、上传、数据中心、作品、评论、数据观测、发布。支持范围按平台分别定义。
- 数据观测展示已有官方 API 读取结果。网页登录与官方 API 授权分开；未授权时提示配置，不生成示例统计冒充账号数据。
- 发布入口进入官方上传或撰写页面，由用户完成内容选择与最终发布，不自动提交。
- 添加、删除、数据观测等弹窗打开时隐藏原生官网视图，关闭后恢复；取消和快速切换应避免晚到的旧视图盖住新页面。

## 官方功能依据

YouTube Studio 提供内容管理、频道数据和评论工具，部分快捷页面需登录后取得当前频道路径。[YouTube 官方说明](https://support.google.com/youtube/answer/2673341?hl=en)

TikTok Studio 网页支持上传、管理内容及评论、查看分析；可用功能受地区及账号条件影响。[TikTok 官方说明](https://support.tiktok.com/en/using-tiktok/creating-videos/creator-tools-on-tiktok)

X 网页可以从撰写框添加视频并发布；快捷入口仅打开官方撰写页面。[X 官方说明](https://help.x.com/en/using-x/x-videos)
