# 主页登录在线判定（2026-09-12）

## 用户规则

公共主页显示当前账号已登录，即确认账号在线，无需打开创作者管理后台。点击账号默认进入公共主页的行为保留；百家号、视频号没有配置公共主页，继续使用管理页。

## 实现

- 抖音、快手、小红书、哔哩哔哩的公共主页通过页面自身当前账号状态或账号专属控件确认登录，不发起管理后台身份请求，不依赖创作者 Cookie 的到期估算。
- 页面加载中、暂未识别、网络暂停或一次检查失败，保留上次登录结论、确认时间和账号资料；左侧主标签显示已保存的账号状态，最近检查原因放在提示中。尚未确认过的账号仍显示待检测或检查状态。
- 主页显示明确未登录入口时复核原在线账号，连续两次确认才离线。导航、页面实例、Cookie 活动变化后丢弃旧检查结果，重新检查。
- 主页证据只更新登录状态，不把公共主页的账号 ID、推荐作者昵称或头像覆盖到管理账号资料。
- 公共主页登录成功不自动触发管理后台采集。验证码页继续使用平台既有验证规则。

## 实测边界

用户选择暂不切换代理。真实国内网页按现有网络模式暂停，因此本轮不声称已验证平台实时 DOM；主页识别通过页面样例、服务集成和界面回归测试验证。未修改代理设置，也未重置登录分区。
