# 视频号头像读取修复

原因：视频号真实 `auth/auth_data` 成功响应中的 `data.finderUser.headImgUrl` 未被身份资料投影保留；登录确认后的资料更新也没有调用头像缓存入口。在线、昵称、粉丝数正常，但头像一直使用首字占位。

修复：从已确认身份的当前账号对象读取 `headImgUrl`，只在主进程内交给既有头像缓存。不会读取推荐作者、封面或管理员头像，不把远程头像地址写入数据库或发送到界面。无效图片地址不改变登录结论，仍使用原账号网络权限及已配置会话匿名下载。

验证：

- 身份解析、观察器、账号服务、图片摄取、媒体网络授权共 161 个测试通过，类型检查及生产构建通过。
- 已覆盖原安装目录 `D:\SJdownloads\创作平台`。安装哈希及时间见 `output/channels-avatar-installed-update.json`。
- 安装版逐个打开三个视频号，三个账号均在线，三个真实头像均有本地缓存且侧栏图片加载成功。实测记录：`output/channels-avatar-installed-check.json`；截图：`output/channels-avatar-sidebar.png`。
- 更新前后的 15 个国内账号和 2 个国外账号的身份、平台和名称均保留。未清理登录会话，未更改代理设置。
- 更新前已按字节备份原程序和数据库，位置见 `output/channels-avatar-backup.log`。沿用上次已发现的数据库完整性异常说明；此次未修复或替换数据库。
